# Git Commands Reference

Complete Git command reference built while learning version control. Covers everything from basic commits to advanced workflows.

## What's Inside

All Git commands organized by topic - from beginner basics to advanced team workflows.

### Topics Covered

- **Setup & Config** - Initial Git configuration
- **Basic Workflow** - Add, commit, status, diff
- **Branching** - Create, switch, merge branches
- **Remote Operations** - Push, pull, fetch, clone
- **Merging & Rebasing** - Integration strategies
- **Stash & Cherry-Pick** - Workflow helpers
- **Reset & Revert** - Undoing changes safely
- **GitHub CLI** - Terminal-based GitHub management

## Why This Exists

Reference I built while learning Git. Everything here is tested and works.

No theory. Just commands with real examples.

## How to Use

- Find your topic in the document
- Copy the command you need
- All examples include descriptions
- Quick reference table at the top for speed

## Command Categories

**Basics:** init, clone, add, commit, status, log  
**Branching:** branch, checkout, switch, merge  
**Remote:** push, pull, fetch, remote  
**Advanced:** rebase, cherry-pick, reset, revert, reflog  
**Tools:** GitHub CLI (gh) commands
